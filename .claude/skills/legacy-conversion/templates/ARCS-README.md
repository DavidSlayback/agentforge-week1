# Arc Planning Files

One file per arc, named `ARC-NN-NAME.md`, written **before** the first slice
in that arc begins: stories, slices, acceptance criteria, and the
`BUGS-MITIGATIONS.md` entries the arc resolves. The roadmap and the arc
template live in `MIGRATION-<ROUTE>.md`.
