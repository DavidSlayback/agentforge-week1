# Final external-communication draft — do not publish automatically

AgentForge is a synthetic, read-only primary-care return-visit preparation
checkpoint. The browser surface supports a patient-scoped briefing,
follow-up, evidence references, qualified partial retrieval, and blocked
cross-patient behavior. The repository includes deterministic evaluation,
redacted observability, signed synthetic context, provider-failure fallback,
and reproducible local load measurements.

This is not a live clinical system. It does not process PHI, retrieve live
OpenEMR records, make diagnoses or recommendations, write to charts, establish
HIPAA compliance, or claim production capacity. The public URL and exact
evidence links must be inserted only after final deployment readback.

**Decision:** local draft only; no recipients, timing, publication, or external
message is approved by this file.
