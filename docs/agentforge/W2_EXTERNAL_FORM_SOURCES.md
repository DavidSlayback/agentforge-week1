# External blank form examples

Reviewed 2026-09-23. The demo links to these official sources so a reviewer can
inspect real form layouts in a separate browser tab. AgentForge does not host,
upload, or process these PDFs. Use the included synthetic scan sample to see
the extraction and worker workflow.

| Source | Form | Notes |
| --- | --- | --- |
| [FDA MedWatch Form 3500](https://www.fda.gov/media/76299/download) | Health professional voluntary adverse-event report; current PDF identified as 09/2025 | Official direct PDF. FDA lists Form 3500 and 3500B as downloadable reporting forms. |
| [CDC Form 50.34 PDF](https://www.cdc.gov/laboratory/specimen-submission/pdf/form-50-34.pdf) | Specimen submission form | Legacy static PDF example. CDC says the 50.34 submission application retires October 30, 2026; CSTOR is preferred. |

The page attributes both sources to their agencies and states that AgentForge is
not endorsed by FDA or CDC. The CDC page warns not to send completed forms by
unsecured email because they may contain personal information. This synthetic
demo has no general PDF OCR or external-provider processing path.
