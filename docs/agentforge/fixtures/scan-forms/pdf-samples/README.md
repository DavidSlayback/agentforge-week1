# Synthetic filled-PDF samples

These four PDFs were created for AgentForge's two assignment document types.
They contain fictional values aligned to `fixture-patient-001`; no source
patient form or third-party template was used. `manifest.json` is the expected
field/value record consumed by the local OCR fixture benchmark.

Each document type has two layouts. Layout A embeds vector text in the PDF.
Layout B embeds a rasterized page image, so it exercises OCR over page pixels.
The layouts vary headings and common field labels while preserving the same
assignment schema. Rasterized here means generated by rendering the synthetic
artwork to an image; it does not simulate a paper scan, noise, blur, or
handwriting.

In the synthetic demo UI, each sample can be downloaded or run directly. The
public sample route is allowlisted and returns only these fixed PDFs.
