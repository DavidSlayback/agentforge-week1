# Synthetic filled-PDF samples

These six PDFs were created for AgentForge's three document types (lab report,
intake form, and medication list). They contain fictional values aligned to
`fixture-patient-001`; no source patient form or third-party template was used.
`manifest.json` is the expected field/value record consumed by the local OCR
fixture benchmark.

Each document type has two layouts. Layout A embeds vector text in the PDF.
Layout B embeds a rasterized page image, so it exercises OCR over page pixels.
The layouts vary headings and common field labels while preserving the same
assignment schema. Rasterized here means generated by rendering the synthetic
artwork to an image; it does not simulate a paper scan, noise, blur, or
handwriting.

The lab and intake PDFs were drawn from the SVGs in this directory. The two
medication lists (`filled-medlist-a.pdf`, `filled-medlist-b.pdf`) are generated
by `agentforge/scripts/generate-golden-pdfs.mjs`; Layout B there is rasterized
with seeded speckle noise, like the generated scanned lab sample.

In the synthetic demo UI, each sample can be downloaded or run directly. The
public sample route is allowlisted and returns only these fixed PDFs.
