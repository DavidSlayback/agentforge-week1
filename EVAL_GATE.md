# AgentForge Week 2 evaluation gate

## Committed inputs

- Runtime prompts are defined in [`agentforge/src/preVisitPreparation.js`](agentforge/src/preVisitPreparation.js). The W2 gate does not call a model or execute these prompts; it checks deterministic extraction, retrieval, validation, and log-redaction behavior.
- The extraction and response schemas are implemented in [`agentforge/src/contracts.js`](agentforge/src/contracts.js), with the source-document extraction contracts in [`agentforge/src/intakeEvidence.js`](agentforge/src/intakeEvidence.js) and [`agentforge/src/labEvidence.js`](agentforge/src/labEvidence.js).
- The 50-case synthetic golden set is generated by the committed `buildW2GoldenSet()` function in [`agentforge/src/w2RegressionGate.js`](agentforge/src/w2RegressionGate.js). Its checked-in baseline and corpus hash are [`docs/agentforge/evidence/W2_BASELINE_REPORT.json`](docs/agentforge/evidence/W2_BASELINE_REPORT.json).

These are repository-tracked source artifacts; there is no separate prompt bundle, schema JSON, or golden-case JSON file. The gate uses synthetic text fixtures, not scanned forms or live model outputs.

## Install and run

Requirements: Node.js 24. No API key, external service, or package installation is needed for the gate.

Install the tracked pre-commit hook in each fresh clone:

```sh
git config --local core.hooksPath .githooks
```

Each `git commit` then runs the gate and is rejected if the command exits nonzero. To remove the hook locally, run `git config --local --unset core.hooksPath`.

Run the same gate directly at any time:

```sh
npm run eval:gate --prefix agentforge
```

## Rubric and failure conditions

The gate runs 50 synthetic cases, 10 per category:

| Category | What it checks |
| --- | --- |
| `schema_valid` | Valid intake and lab extraction output passes the strict contracts. |
| `citation_present` | Extracted facts retain source document, page, field, quote, and bounding-box provenance. |
| `factually_consistent` | Known lab values match expected values and guideline retrieval includes the expected source and provenance. |
| `safe_refusal` | Malformed documents are qualified and unsupported queries return no evidence. |
| `no_phi_in_logs` | Synthetic sentinel content is absent from serialized traces after redaction. |

It fails unless there are exactly 50 cases, every category scores at least 95%, no category regresses more than 5 percentage points from the checked-in baseline, and there are zero failures in `no_phi_in_logs`. A baseline corpus-hash mismatch also fails the gate. The report includes category rates, regressions, critical failures, and failed case IDs.

For a local negative-control check, run:

```sh
npm run eval:gate --prefix agentforge -- --inject-defect
```

This injects one schema failure and should exit nonzero.

## Environment

The gate requires no secrets or environment variables. It uses the local lexical retrieval implementation and synthetic fixtures; it does not call Cohere or another model provider.
